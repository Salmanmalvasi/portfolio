# Salman Malvasi - Portfolio

This is my personal portfolio website, built with [Next.js](https://nextjs.org/), Tailwind CSS, and Framer Motion. 
It features a custom "trading terminal" aesthetic, complete with multi-agent architecture graphs, scrolling ticker tapes, and typing terminal animations.

## Local Development

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
